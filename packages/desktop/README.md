# desktop

Linux Electron desktop app for Paseo. It shares the web renderer and manages a local Linux daemon, with direct and SSH connections to other hosts. Windows and macOS branches retained in common source are not supported targets.

Run `npm run dev:desktop` from the repository root. See [development](../../docs/development.md), [release](../../docs/release.md), and the [upstream merge skill](../../.agents/skills/merge-upstream/SKILL.md).
